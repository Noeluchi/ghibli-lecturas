# Lecturas de Ghibli

Landing responsive basada en el wireframe de Figma. HTML, CSS y JavaScript sin dependencias. Todos los archivos están en la raíz para GitHub Pages.

Paleta: #FBFAF7, #2E3036 y #087FBE. Jost Medium, equivalente geométrica autorizada en sustitución de Futura/Avant Garde. Fuentes locales con licencia OFL adjunta.

## Suscripción

El formulario valida correo y consentimiento y prepara una solicitud dirigida a lucialbiach@gmail.com. El visitante debe enviar el mensaje. La web no guarda direcciones ni afirma que el alta ha finalizado. Incluye alternativa para redactar en Gmail o copiar la solicitud. Altas, confirmaciones, avisos y bajas se gestionan manualmente. No hay automatización del catálogo o de los envíos. Para automatizar hace falta un proveedor de correo y completar la identificación del responsable. Nunca introducir claves privadas en JavaScript público.
